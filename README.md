# Sistema de gestão de pastelaria

Planejamento de um sistema para gerenciar pedidos, acompanhar o preparo e imprimir comandas de uma pastelaria com três unidades: Centro, Norte e Sul.

## Status

O projeto está na fase de especificação. Este repositório contém os requisitos e o desenho técnico; a aplicação ainda não foi implementada.

## Documentação

- [Requisitos](.kiro/specs/sistema-gestao-pastelaria/requirements.md)
- [Desenho técnico](.kiro/specs/sistema-gestao-pastelaria/design.md)

## Funcionalidades planejadas

- Cadastro de pedidos para balcão, retirada e entrega.
- Acompanhamento dos pedidos por status.
- Dashboard de vendas por unidade.
- Impressão de comandas em impressoras térmicas.

## Tecnologias previstas

React com TypeScript no frontend, FastAPI com Python no backend e SQLite para persistência dos dados.
